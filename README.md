# QuickCapture

Windows 11용 독립 캡처 및 녹화 앱입니다. 기본 설정에서는 스크린샷을 PNG로 먼저 저장하고, 클립보드가 잠겨 있으면 백그라운드에서 잠시 재시도합니다.

| 단축키 | 기능 |
| --- | --- |
| `Win + Shift + S` | 직사각형, 창, 전체 화면, 자유형 캡처 |
| `Win + Shift + R` | 영역 또는 창 녹화 |
| `Win + Shift + T` | 텍스트 추출 |
| 캡처 중 `Ctrl + E` | 빠른 마크업 |
| 영역 조정 또는 마크업 중 `Ctrl + C` | 현재 이미지를 복사하고 캡처 창 닫기 |
| 캡처 중 `Esc` | 취소 |

편집 창에서 펜, 형광펜, 지우개, 도형, 이모지, 자르기, 실행 취소, 로컬 OCR, QR 인식, 텍스트 가리기를 사용할 수 있습니다. 녹화에서는 마이크 및 시스템 오디오를 선택하고, 결과를 자르거나 GIF로 내보낼 수 있습니다. 기본 저장 위치는 Windows 사진 및 동영상 폴더 안의 각각의 `QuickCapture` 하위 폴더입니다.

- **이번 캡처만 저장 없이 사용** — 캡처 막대에서 **PNG 저장**을 끕니다. 클립보드 자동 복사 설정은 따로 적용됩니다. 항상 자동 저장을 끄려면 설정의 **스크린샷 PNG 자동 저장**을 끕니다.
- **선택한 영역 조정** — 직사각형이나 창을 선택한 뒤, 영역 안쪽을 드래그해 이동하거나 테두리 손잡이를 끌어 크기를 조정합니다. **완료** 또는 `Enter`로 확정합니다. 한 번에 캡처하려면 **선택 후 조정**을 끕니다.
- **복사 후 닫기** — 조정 중 `Ctrl + C`로 현재 영역을 확정하고 클립보드에 복사합니다. 자동 복사가 꺼져 있어도 이 단축키로 복사할 수 있습니다. PNG 저장 여부는 캡처 막대의 설정을 따릅니다.

## 빌드와 실행

Windows 11 x64, .NET Framework 4.8 이상, PowerShell이 필요합니다. 저장소 루트에서 실행합니다.

```powershell
.\restore-dependencies.ps1
.\build.ps1
.\dist\QuickCapture.exe
```

복원 스크립트는 버전과 SHA-256이 고정된 NuGet 패키지 및 FFmpeg를 각 배포처에서 받습니다. 다른 PC에 복사할 때는 `dist` 폴더 전체를 옮깁니다. 메인 창 없이 트레이에서 시작하려면 `QuickCapture.exe --tray`를 사용합니다.

## Windows 캡처 도구와의 차이

비교 기준은 Windows 11용 Microsoft.ScreenSketch `11.2608.41.0`입니다. 편집 화면을 별도로 구현했으며, 자동 맞춤의 콘텐츠 경계는 로컬 알고리즘으로 판정합니다. Bing 시각 검색은 브라우저를 열어 이미지 붙여넣기를 사용합니다. Click to Do는 지원되는 Windows에서 시스템 기능을 열고, 그 외에는 로컬 텍스트 작업을 엽니다. OCR 언어는 Windows에 설치된 인식 언어를 사용합니다.
